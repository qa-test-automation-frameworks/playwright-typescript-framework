## Feature currency review — 2026-10-16

The package and CI browser image now pin Playwright `1.64.0`. Official release notes and
documentation were checked on this date. This review records concrete decisions; it does not claim
that every Playwright feature belongs in this API/UI framework.

| Capability                                     | Current implementation                                                                                                                                                        | Official support checked                                                                                                                                                                                   | Benefit and compatibility risk                                                                                                                                                                 | Decision and proof                                                                                                                                                                                                                      |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Per-test fixture and browser-context isolation | Playwright gives each test an isolated context; the owned target uses synthetic test identities.                                                                              | [Fixtures](https://playwright.dev/docs/test-fixtures) and [browser contexts](https://playwright.dev/docs/browser-contexts) describe test-scoped setup/teardown and isolated browser state.                 | Prevents cookie/storage crossover. Risk remains shared server data; context isolation alone does not isolate backend records.                                                                  | **Retain.** Existing API/UI tests and owned-target setup/teardown controls verify cleanup boundaries.                                                                                                                                   |
| Retry traces and diagnostics                   | CI records traces on first retry and retains failure screenshots/video; diagnostics redact request and response secrets.                                                      | [Trace viewer](https://playwright.dev/docs/trace-viewer) documents action, DOM, network and attachment inspection; [test configuration](https://playwright.dev/docs/test-use-options) defines trace modes. | Reduces time to reproduce browser failures. Retaining all traces would increase artifact volume and could expose data, so traces stay bounded to retries.                                      | **Retain bounded capture.** Exact Playwright CI `38925779907` passed on 1.64.0, including the required API, browser, accessibility, visual, evidence and reporting jobs; optional Allure publication remained skipped on the PR event.  |
| Sharded report merging                         | Browser and visual suites shard in CI; the Allure merger and native-evidence aggregator validate expected shards, duplicates, counts and outcomes.                            | [Sharding](https://playwright.dev/docs/test-sharding) and [blob reports](https://playwright.dev/docs/test-reporters#blob-reporter) support native Playwright report merging.                               | Blob reports preserve native attachments and simplify Playwright HTML merging. A second report stream adds storage and duplicate presentation beside the current Allure and schema-v3 outputs. | **Defer blob reporter.** Current merged Allure and native execution evidence cover reviewer and machine consumers; CI validates missing/duplicate shard rejection. Reconsider if native Playwright HTML becomes a reviewer requirement. |
| Semantic locators                              | UI assertions prefer role, label and accessible-name locators; selector-contract tests isolate explicit test IDs.                                                             | [Locators](https://playwright.dev/docs/locators) recommends user-facing locators and documents role/label locators.                                                                                        | Better resilience to harmless markup changes; accessible names become part of the contract.                                                                                                    | **Retain.** The selector fault control proves the contract gate fails with a useful diagnostic.                                                                                                                                         |
| Accessibility and visual checks                | Axe scans critical pages; screenshot assertions use reviewed baselines and a snapshot manifest.                                                                               | [Accessibility testing](https://playwright.dev/docs/accessibility-testing) and [visual comparisons](https://playwright.dev/docs/test-snapshots) document these checks and environment-sensitive rendering. | Finds accessibility and rendering regressions. Browser/OS/font differences can create false visual diffs, so baselines remain platform-specific and reviewed.                                  | **Retain.** CI runs the accessibility suite and Windows visual shards; snapshot hygiene is a separate gate.                                                                                                                             |
| Test-order randomization                       | `test:api:shuffle` runs the API suite with one worker, no retries and fixed seed `271828182`; a local Node 24.21.0/npm 10.9.4 run passed 32/32 against the controlled target. | [Release notes](https://playwright.dev/docs/release-notes) for 1.64 add `--shuffle` with a reproducible seed.                                                                                              | Detects order-coupled tests while preserving a repeatable failure. One seed cannot prove independence across every ordering.                                                                   | **Adopt in the API gate.** Exact 1.64.0 CI `38925779907` passed with the regular API suite; broader seed exploration remains optional follow-up.                                                                                        |
| Browser version support                        | The container matches Playwright 1.64.0; CI exercises Chromium, Firefox and WebKit smoke coverage, plus Windows Chromium visual baselines.                                    | [Browsers](https://playwright.dev/docs/browsers) ties browser binaries to Playwright releases; [release notes](https://playwright.dev/docs/release-notes) publish the tested browser versions.             | Matching package and browser image prevents protocol/version drift. It does not imply equivalent coverage on every branded browser or OS.                                                      | **Pin together and limit claims.** Linux/Windows CI remains the compatibility evidence; no universal BiDi or browser-channel claim is made.                                                                                             |

The 1.64.0 upgrade and shuffle gate are compatibility changes, not a dependency-only green check.
